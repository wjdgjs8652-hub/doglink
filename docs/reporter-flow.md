# DOG-LINK 시민 제보자 플로우

## 전체 흐름

```text
S1 진입 (/)
→ S2 사진 촬영·업로드 (/report/photo)
→ S3 위치 확인 (/report/location)
→ S4 목격 내용 선택 입력 (/report/details)
→ S5 AI 상태 판정 (/report/triage)
→ (응급 판정 시) S5-E 응급 자동신고 확인 (같은 라우트의 바텀시트)
→ S6 접수 완료 (/report/complete/:id)
→ S7 상태 확인 (/report/status/:id)
```

보조 라우트:

- `/report/status` — 접수번호 직접 입력 (S1 보조 링크, S7 오류 폴백)
- `/design-system` — 컴포넌트 미리보기

## 분기 규칙

| AI 판정 | 흐름 |
|---|---|
| **emergency** | S5 → S5-E 카운트다운(10초, 연장 가능) → 신고 실행 또는 「응급이 아니에요」 → S6. 중단 시 응급 신고만 취소되고 일반 접수로 전환 |
| **dispatch** | S5 → S6. 구조 출동 확인 대상 상태로 접수 |
| **negative** | S5 → 대응 필요성 낮음 안내 + "제보 기록은 남겨두며 담당자가 최종 확인합니다" → S6 |
| **unavailable** (10초 초과·오류) | 판정 대기 없이 즉시 일반 접수 → S6. "AI 분석이 지연되어 우선 제보를 접수했어요" 안내 |

**어떤 판정·오류에서도 제보 데이터는 접수됩니다.** 접수 실패 시에도 draft는 보존되어 재시도할 수 있습니다.

## 상태 보존

- 전역 상태: `ReportDraftContext` (React Context) + sessionStorage 미러링
- 뒤로가기: 라우트 이동과 무관하게 사진·위치·칩·텍스트 유지
- 새로고침: sessionStorage에서 복원 (사진은 용량 초과 시 제외될 수 있음 — best effort)
- 제출 성공 시에만 `clearDraft()`로 임시 데이터 정리
- 이전 단계 데이터 누락 시(예: 사진 없이 S3 직접 진입) 해당 단계로 자동 리다이렉트

## 응급 카운트다운 방어 로직

- 최소 10초, 숫자 + 진행 바 동시 표시, `aria-live="assertive"`
- 「시간이 더 필요해요」 버튼으로 10초씩 연장
- 탭이 백그라운드로 이동하면 `visibilitychange`로 카운트다운 일시정지 → 화면 복귀 후 재개 (사용자가 보지 못한 채 실행되는 것을 방지)
- 「응급이 아니에요」는 실행 버튼과 동등한 크기·대비

## 개인정보 처리

- 이름·전화번호·이메일 등 개인정보를 수집하지 않음
- 사진은 canvas 재인코딩으로 EXIF(GPS 포함) 제거 후 사용
- 원본 좌표는 접수 처리에만 사용, 공개 상태 화면에는 동/읍 단위 범위 라벨(`publicLocationLabel`)과 반경만 표시
- 제출 완료 후 sessionStorage의 임시 위치·사진 데이터 삭제

## 오류 대응 요약

| 상황 | 대응 |
|---|---|
| 카메라 권한 거부·미지원 | 앨범 업로드 폴백 상시 제공 |
| 업로드 실패 | 썸네일에 「다시 시도」 오버레이 |
| GPS 거부·시간 초과 | 주소 검색·장소 검색·직접 입력 폴백, 제보 계속 가능 |
| AI 분석 지연·실패 | 10초 후 일반 접수 자동 진행 |
| 접수 실패 | draft 보존 + 재시도 안내 |
| 잘못된 접수번호·만료 링크 | 다시 시도 / 접수번호 재입력 / 홈 이동 3개 행동 제공 |
