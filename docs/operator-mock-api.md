# DOG-LINK 운영자 콘솔 — mock / 실제 연동 구분 문서

이 콘솔은 실제 백엔드 없이 동작하는 시연용이다. UI는 `operator/js/services.js`의
서비스 인터페이스만 사용하므로, 실제 연동 시 이 파일의 구현만 교체한다.
**mock을 실제 연동처럼 표기하지 않는다** — 화면 곳곳에 mock 여부가 명시돼 있다.

## adapter 현황

| 서비스 | 현재 구현 (mock) | 실제 연동 시 필요한 것 |
|---|---|---|
| auth | 시연 계정 4개(운영자 3 + 총괄 `admin`/`doglink-super` — 권한 등급은 동일, 문서에 권한 체계가 없어 만들지 않음), sessionStorage 세션(30분, 활동 연장) | 공공 SSO / 기관 계정 서버. `login/currentSession/logout` 교체 |
| operator-report / queue | 메모리 배열(`mock-data.js`), 새로고침 시 초기화 | 조회 API + 서버 필터·정렬·페이지네이션 (현재 클라이언트 검색은 소규모 데이터 전제) |
| transition | `requestTransition` — 상태 머신 검증 + 감사 로그를 동기 단일 함수로 처리 | **서버 트랜잭션 필수**: 상태 변경과 감사 로그가 한쪽만 성공하면 안 됨. 실패 시 클라이언트는 롤백 + 오류 토스트 경로 유지 |
| triage override / matching | 로컬 반영 + 감사 로그. 유사 점수는 규칙 기반 가중 합산(털색30·무늬20·크기15·목줄10·거리15·시간차10, 45점 미만 컷) | AI 매칭 API. 무관 판정 후 재제안 정책은 서버 정책 따름 |
| notification (보호자 알림) | 발송 확인 **기록만** 남김 — 실제 문자·푸시 미발송(다이얼로그에 명시) | 알림 발송 API + 발송 결과 수신 |
| realtime | 30초 polling 시각 갱신 + 계정 메뉴의 "시연 도구"로 신규 일반/응급 제보 수동 주입 | SSE 또는 WebSocket (`OperatorRealtimeEvent` 형태 이벤트) |
| map | SVG mock 지도 패널(제주 실루엣, 화면 좌표계 720×380) + 좌표 목록 폴백. 클러스터·줌 자체 구현 | Kakao/Naver Maps SDK + API 키. 로드 실패 시 현 mock 패널이 폴백 |
| statistics | 메모리 데이터 집계 | 집계 API. 지표 정의는 데이터 계약 정의 우선 |
| export | CSV 클라이언트 생성(실동작, BOM 포함) / PDF는 브라우저 인쇄 화면(버튼에 명시) | 서버 PDF 생성 API |

## 시연용 데이터

- 사건 12건(`JJ-4810`~`JJ-4824`): 8개 상태 전부 + 응급 미처리 17분 경과 1건 + 응급 자동신고(초 단위 이력) 1건 + 판정 번복 이력 1건 + 실종 연결 1건 + 종결/부정 종결(기본 큐 숨김) 각 1건
- 실종 신고 3건(`LOST-201~203`), 운영자 3명(김담당·박주무관·이주무관)
- 전부 한국어 실제형 더미이며 실제 인물·연락처가 아니다. 위·경도는 화면 좌표에서 환산한 시연용 값
- 상태는 메모리에만 있고 영속화하지 않는다(새로고침 = 초기화). 설정(사운드)만 localStorage

## 보안·개인정보 구현 메모

- 시민 S7 응답(`citizenView`)은 정확 좌표·상세 주소·담당자 정보를 **필드 자체에서 제거**해 투영 (상세 패널의 "시민 상태 화면(S7) 미리보기"로 검증 가능)
- 통계·내보내기에는 개인정보·정확 좌표 미포함 (CSV 메타 행에 명시)
- 사용자 유래 문자열은 전부 `DL.esc()`로 이스케이프 후 DOM 삽입 (XSS 방지)
- 사건번호(`JJ-48xx`)는 내부 연속 ID와 분리된 표기용 번호라는 전제
- 콘솔 로그에 좌표·토큰 출력 없음 / 인증 토큰 하드코딩 없음
- 문서에 없는 역할·권한 체계는 만들지 않았다(운영자 단일 역할, 삭제·대량 수정·사용자 관리 기능 없음)

## 알려진 한계

- 동시성(다른 담당자가 먼저 변경) 시나리오는 단일 브라우저 mock에서는 재현 불가 — 오류 문구·롤백 경로만 구현돼 있으며 서버 연동 시 충돌(409) 응답에 연결해야 한다
- 병합 취소는 미구현이며 UI에 "확정 전 취소만 가능"으로 명시
- 부정 종결 되돌림 미구현 — 확인 다이얼로그에 정책으로 명시
